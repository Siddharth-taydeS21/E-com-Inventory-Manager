## 🛒 Ecom Inventory Manager

A frontend inventory management application built to practice **CRUD operations and real-world REST API integration** using JavaScript and MockAPI.io.

The goal of this project was to build an application that can create, display, update, and delete products while understanding how a frontend communicates with a backend through HTTP requests.

Instead of waiting until I learned Node.js and Express.js to build my own backend, I used MockAPI.io as a lightweight REST API and focused on developing the frontend and understanding API communication.

---


## ✨ Features
#### 📦 Product Management
- Create: Add new products to the inventory.
- Read: Fetch and display products from the REST API.
- Update: Edit existing product information and save changes through API requests.
- Delete: Remove products from the inventory.


#### 🔗 REST API Integration
- Integrated Cloudinary to work with product images.
- Added image handling as part of the product management workflow.


#### ✅ Form Validation
- Implemented validation for product inputs.
- Practiced handling invalid data before submitting requests.
- Improved the reliability of product creation and editing workflows.


#### 🔄 Dynamic UI Updates
- Connected frontend interactions with API responses.
- Updated the interface based on product operations.
- Practiced managing asynchronous operations and communicating the results of API requests to the user.

## 🎯 Why I Built This Project

My goal was to understand how CRUD applications work beyond the user interface.

At the time, I was focused on frontend development and had not yet learned Node.js and Express.js well enough to build my own backend. Rather than postponing the project, I used MockAPI.io to simulate the backend and focus on the frontend's interaction with a REST API.

This helped me understand how HTTP methods, API endpoints, request payloads, and server responses fit together in a real application workflow.

**The biggest takeaway**: You don't need to master every part of the stack before building something useful. Choosing the right tools for your current learning stage can help you gain practical experience while continuing to grow.
